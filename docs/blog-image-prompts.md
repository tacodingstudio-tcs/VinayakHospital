# Blog cover images: prompts

How to use
1. Paste a prompt into your image tool. Generate 16:9 landscape (about 1600 x 900).
2. Pick the best result, save as JPG or WebP under 400 KB, and name it exactly as shown.
3. Put the files in `web/public/img/blog/` and tell me. I will set each post's cover.

Shared style line (add to every prompt):
"Warm, soft natural light, realistic photographic style, Indian family, calm and reassuring mood, clean hospital or home setting, no text, no logos, no watermarks, no medical equipment close-ups, natural hands and faces."

Please label AI-made images as illustrations on the site if they depict people, and check each face and hand carefully before use.
